# Sum of Two Numbers

## Problem Description

Given two integers A and B, calculate their sum.

This is a simple example problem to demonstrate the COMMIT Romania problem format.

## Input Format

The input consists of a single line containing two integers A and B separated by a space.

## Output Format

Output a single line containing the sum A + B.

## Constraints

- -10^9 ≤ A, B ≤ 10^9
- Time Limit: 1 second
- Memory Limit: 256 MB

## Sample Input

```
3 5
```

## Sample Output

```
8
```

## Explanation

The sum of 3 and 5 is 8.

## Notes

This is a basic example problem. Real COMMIT problems will be more complex and require algorithmic thinking.
