# Contributing to COMMIT Romania

Thank you for your interest in contributing to the COMMIT Romania supporting code! This document provides guidelines for contributing to the project.

## How to Contribute

### 1. Fork and Clone

1. Fork this repository on GitHub
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/COMMIT-ROMANIA.git
   cd COMMIT-ROMANIA
   ```

### 2. Create a Branch

Create a new branch for your contribution:
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes

- Follow the existing code style and conventions
- Add tests for new functionality when applicable
- Update documentation as needed
- Ensure your changes don't break existing functionality

### 4. Commit and Push

```bash
git add .
git commit -m "Description of your changes"
git push origin feature/your-feature-name
```

### 5. Create a Pull Request

Submit a pull request on GitHub with a clear description of your changes.

## Contribution Areas

We welcome contributions in the following areas:

- **Problem Templates**: Create standardized templates for COMMIT problems
- **Testing Tools**: Develop automated testing and validation tools
- **Documentation**: Improve guides and documentation
- **Utility Scripts**: Add helpful scripts for competition management
- **Examples**: Provide example solutions and implementations

## Code Style

- Use clear, descriptive variable and function names
- Add comments for complex logic
- Follow language-specific conventions (Python PEP 8, etc.)
- Keep functions focused and modular

## Testing

- Add tests for new functionality
- Ensure all existing tests pass
- Include edge cases in your tests

## Documentation

- Update relevant documentation when making changes
- Use clear, concise language
- Include examples where helpful

## Questions?

If you have questions about contributing, please open an issue or reach out to the maintainers.

Thank you for helping make COMMIT Romania better! 🇷🇴
