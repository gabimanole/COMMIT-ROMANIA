## About COMMIT

COMMIT is a prestigious programming competition in Romania that focuses on:
- Algorithmic problem solving
- Competitive programming skills
- Mathematical foundations
- Clean code implementation

This documentation helps participants, organizers, and contributors understand and use the supporting tools effectively.
